# Fitness Hub

Fitness Hub is a comprehensive online fitness and wellness platform that helps users achieve their health goals through workout plans, exercise programs, yoga sessions, and fitness product shopping.

## Features

* User Registration and Login
* Admin Login and Dashboard
* Personalized Workout Plans
* Multiple Exercise Categories
* Yoga Programs and Guidance
* Fitness Product Store
* Protein Supplements and Fitness Accessories
* Add to Cart Functionality
* Order Management
* UPI and Multiple Payment Options
* Responsive and User-Friendly Interface

## Project Objective

The goal of Fitness Hub is to provide users with a single platform for fitness training, wellness activities, and fitness-related shopping, making it easier to maintain a healthy and active lifestyle.

## Technologies Used

* Python
* Flask
* HTML
* CSS
* JavaScript
* SQLite / Database
